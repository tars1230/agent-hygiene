微信内存结构

小程序容器占微信内存近半

微信的内存大头不是聊天，是小程序容器（WeChatAppEx.exe）—— 零可见窗口、CPU 常年 0.00%，纯占内存不干活。
🔴 实测杀掉它没用：15 秒内微信会重新拉起，可用内存反而 −0.22GB。 要省只能关入口：微信 → 设置 → 通用 → 发现页管理 → 关掉小程序 / 视频号。
微信输入法（wetype_*）是独立进程组，跟微信本体无关，可单独关。
